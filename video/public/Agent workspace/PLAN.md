# A little room to read

## The plan

Build a quieter way to review the Markdown your AI agent leaves behind. Open the file, find the useful part, and keep moving.

> Your agent did the writing. Now make it a pleasure to read.

## Three small steps

| Step | What happens |
| --- | --- |
| Preview | Select a Markdown file and press Space on Mac. |
| Explore | Open SlayDown for an outline, search, and reading styles. |
| Edit | Send the original file to your favorite local editor. |
