# The quiet work

Some ideas deserve a little room. A clear page, a comfortable rhythm, and space to follow a thought all the way through.

## Start with a thought

Good work often starts small: a sentence in your notes, a sketch of a plan, a question worth keeping.

> Make room for the words that matter.

### Keep what matters

- A place for the next idea
- A clear view of the details
- A little less distraction

## Find a rhythm

Read slowly. Follow the outline. Return to a phrase. The page stays simple, so your attention can stay with the work.

| A small habit | A clearer day |
| --- | --- |
| Write it down | Keep the idea |
| Read it back | See the shape |
| Make some space | Find the next step |

## Even the details

Code belongs here too, with just enough color to make the structure clear.

```js
const thoughts = await open('field-notes.md');

function makeRoom(thoughts) {
  return thoughts.filter(idea => idea.matters);
}
```
